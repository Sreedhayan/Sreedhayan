# ⚙️ My Development Philosophy

```python
while True:

    idea = imagine()

    if idea:
        prototype(idea)

    if prototype_is_broken():
        learn()

    improve()

    repeat()
```

### My rules:

**01 — Build > Watch**

Learning becomes much more interesting when you actually build something.

**02 — Curiosity is a superpower**

If something makes me think *"wait... how does that work?"*, I investigate it.

**03 — Break things**

Experiments don't always work. That's part of the process.

**04 — Stay open**

Open-source software, open knowledge and open experimentation accelerate everyone.

**05 — Think long-term**

Today's weird experiment could become tomorrow's useful technology.
